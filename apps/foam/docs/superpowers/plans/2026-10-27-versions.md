# Versions (Foam Phase 7, Spec 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** A night picks a version of a scene by its seed, through `night.pick` with a key and the
odds of each name: the friend's evening in three versions whose hours the texts name, Rotor's corner
table in three, and an event on arriving at three stops that marks itself on the night and shows
once; the checker runs every name of every table and reports odds that do not sum to 1.

**Architecture:** `pick` on the night reads `random(key)` once and holds it against the running sum
of the odds; `events` is a list of keys with `meet` and `hasMet`. The checker replaces `pick` with
one that notes the tables and returns the name at the run's index, runs a function that picked once
per name of its longest table, and carries the events met into the fresh nights and the second pass.
In the content, `getFriendEvening` picks `'friend'`, the corner table's `start` picks
`'cornerTable'`, and each stop's description becomes a script whose `start` picks the arrival's
event unless it was met. `formatHourWords` writes the evening's hours.

**Tech Stack:** TypeScript 6 (`exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`), Tellurion
(`Dialogue`, `TextInput`), Vitest 4 (`unit` in Node, `browser` in Playwright's Chromium), Prettier
3, Turborepo.

**Spec:** `apps/foam/docs/superpowers/specs/2026-10-26-versions-design.md`

Runs after spec 1, which is built: `night.random` as the hash of the seed, the six values of
`CHECK_RANDOM` run where a function reads it, the New night window and the jump-in's `seed=`. The
direction document already carries the Variation row and the phase 7 paragraph's link to the spec
(commit a998098e); this plan only states that the spec is built.

  ternaries) and lint fails on a difference: run `npx prettier --write` on the task's files before
  lint. Lint has `max-params` at 3 as a warning: a new helper takes at most three.

  with a field only when it has a value.

## Review Focus

- **Today's seed in the browser suites.** `startFrom` starts a night on the window's date, and the
  date 2026-10-27 picks the sooner evening and the wallet: the quest suite's bartender test expects
  "eleven" at 21:00 and fails on such a date. A test that reads a version names a seed whose night

- **A table that sums to 1 on paper and to 0.9999999999999999 in doubles**,
  `{a: 0.7, b: 0.2, c: 0.1}`. The checker does not report it, and `pick` at 0.9999999999999999 gives
  the last name. Pinned in Task 1 (`pick`) and Task 3 (the checker).
- **An empty table.** `night.pick('key', {})` has no name to give; the checker reports its odds
  summing to 0 under the function's path. Pinned in Task 3.
- **The fight before 22:00 and after it on one night.** At 21:59 the arrival is the plain
  description and nothing is met, so the same night meets the fight at 22:00. Pinned in Task 6.
- **The wallet's text and its effect agree.** The text names 200 Kč and Keep the money adds 200 Kč,
  because both draw `'walletMoney'` once. Pinned in Task 6 (the number pinned) and Task 7 (the
  night's own hash).
